This R implementation of the models LINTUL-1 and LINTUL-2 is an archive model that is not actively maintained. However, we do maintain one single LINTUL version that is implemented in Python ([link](https://github.com/model-library-pps/LINTUL)). This version is capable of simulating potential, water-limited, and water-and-nitrogen limited growth.
