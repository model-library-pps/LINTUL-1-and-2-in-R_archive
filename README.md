**Name**\
LINTUL-1 & 2 in R with parameters for spring wheat and maize

**Program type**\
R

**Available since**\

**Description**\
A checked version of  LINTUL1 (potential) and LINTUL2 (water limited)  crop growth models in R, producing exactly the same results as the original FST version for spring wheat.
